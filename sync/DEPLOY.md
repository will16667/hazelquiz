# HazelQuiz 雲端（最短步驟）

用管住 Drive「HazelQuiz」嗰個 Google：

1. 開 https://script.new → 專案名 **HazelQuiz Sync**
2. 貼上同資料夾 `Code.gs` 全文 → 儲存
3. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** → Deploy → 授權 Drive
4. 複製 `/exec` 網址，回覆畀 Grok Bot（或自己貼去網站 `#/sync`）

之後朋友開 https://will16667.github.io/hazelquiz/ **唔使登 Google**，生字會寫入你 Drive 嘅 `hazelquiz-shared-bank.json`。

唔好改 Open Readle。
