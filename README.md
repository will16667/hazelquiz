# HazelQuiz（溫書關卡）

獨立於 Open Readle 的護理 Life Sciences 溫書網。

## 流程
1. **讀全文** — Lecture 1 / 2 / 3，點英文睇解釋／發音／存生字
2. **溫重點** — 21 關雙語筆記卡
3. **測驗通關**
4. **生字／複習** — SRS；可開 **雲端同步**

## 雲端同步
- 本機：`localStorage`（`hazelquiz-v1`）永遠保留作快取／離線
- 線上：Google Apps Script → Drive 資料夾內 JSON（見 `sync/DEPLOY.md`）
- 設定頁：`#/sync`（生字頁亦有入口）
- 另備 JSON 匯出／匯入
